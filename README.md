# Pomodoro Time — FastAPI Learning Project

Pomodoro Time is a learning backend project created while completing the  
**“Python. Microservices. Backend with FastAPI”** course on Stepik.  
The main goal of this project was to take the first practical steps in backend development using FastAPI.

During development, I focused on understanding core backend concepts: API design, asynchronous Python, configuration management, database interaction, and integration with external services. The project itself is intentionally simple — the emphasis is on learning architecture and backend tools rather than complex business logic.

The project uses a modern backend stack including **FastAPI, Pydantic v2, SQLAlchemy 2, Alembic, PostgreSQL, and Redis**, with **Poetry** for dependency and environment management. Testing and async-related tooling were also explored as part of the learning process.

This repository represents my entry point into backend development and serves as a foundation for further growth and more advanced projects.
